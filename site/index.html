What is PlayOS

A console soul for handheld PCs

PlayOS is an open-source operating system that gives handheld gaming PCs a console experience — built for a controller, booting straight into your games, and designed so the system takes care of itself.

A console, not a desktop

No desktop, no windows, no package manager. PlayOS boots into a game library you can drive entirely with a gamepad.

Your data, protected

The system image is read-only and updates are A/B with automatic rollback. Your games, saves, and settings live on a separate writable partition.

Games stay untrusted

Every game runs in a sandbox with no access to the rest of the system — a broken or malicious game cannot wreck your device.

Today

What players get today

Everything here is running on real hardware now — the ASUS ROG Ally is the first reference device, with Intel graphics brought up on the ASUS ZenBook UX530.

Controller-first everything

The library, settings, and the in-game menu are all built for a gamepad. Pick up the controller and leave the keyboard in the drawer.

Boot straight into your games

No desktop, no windows, no setup. PlayOS boots into your game library in seconds and gets out of the way.

Fast, direct graphics

A native compositor draws games straight to the display with zero-copy scanout — measured 100% direct on the ROG Ally.

A system that protects itself

Read-only system image, A/B updates with automatic rollback, and every game sandboxed. A bad update or a bad game can't wreck your system.

Audio, power, and Wi-Fi handled

ALSA audio with proper device routing, battery and thermal status, suspend, and a built-in Wi-Fi stack — the OS does the chores.

Games from any engine

PlayOS exposes one stable C API — libplayos — that any engine or toolchain can target. The SDK ships with a ready-to-use toolchain and raylib.

Where the platform is going

These are the services PlayOS is building toward. None of them are live today — and when they arrive, they will stay optional: a device without an account will keep working, offline play always works.

Coming

Per-player profiles on one device — separate saves, settings, and screenshots for everyone who shares a handheld.

Coming

PlayOSUniverse accounts

Coming

PlayOS Marketplace

Discover and install games packaged as signed .gpk bundles, with free content available to every device.

Coming

Cloud saves

Your progress will follow you between devices — and local saves keep working offline, always.

Achievements & trophies

Developers

Built in the open

Every part of PlayOS is open source under the PlayOS Foundation. Games target one stable C API — libplayos — and the reference SDK ships as a relocatable musl toolchain with raylib.

  • Linux is the hardware layer, not the product.
  • The system image is immutable; only the data partition is writable.
  • The compositor permanently owns DRM/KMS — no handoffs to games.
  • One game runs at a time; the shell always stays alive.
  • Games target playos-platform-api; they never touch compositor or kernel internals.

One open platform

playos-init PID 1 init and system supervisor — boots the OS, supervises compositor/shell, launches games. playos-compositor Minimal wlroots compositor owning DRM/KMS, Wayland sessions, focus, and input routing. playos-shell Raylib-based console interface for launching and managing applications. playos-runtime Trusted control IPC and policy — the shell and overlay's channel to the platform. playos-platform-api Reference implementation of the public libplayos C ABI (input, audio, display, storage, power, logging, lifecycle). playos-refdistro Buildroot assembly — builds the immutable, bootable image for ROG Ally, Intel, and QEMU. playos-spec The official specification, architecture, RFCs, and developer documentation. playos-tools Packaging, project templates, build utilities, deployment, and SDK tooling. playos-samples Sample applications and tutorials demonstrating the Platform API. playos-marketplace Open marketplace for publishing, discovering, and installing games and content. playos-cloud Self-hostable cloud services: accounts, cloud saves, achievements, leaderboards. playos-foundation This website — governance, community guidelines, and branding.
