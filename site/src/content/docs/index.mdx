## Built for one thing: playing games

A focused console experience — no desktop, no distractions, no Linux knowledge required.

    <h3>Controller-first shell</h3>
    <p>A Raylib-based interface driven entirely by gamepad. Games and menus are navigable with the same controls, end to end.</p>
  </div>
  <div class="pos-card">
    <div class="pos-card-icon purple" aria-hidden="true">

      </svg>
    </div>
    <h3>Native compositor</h3>
    <p>A minimal wlroots compositor that permanently owns DRM/KMS — low-latency, tear-free output with no handoff to games.</p>
  </div>
  <div class="pos-card">
    <div class="pos-card-icon green" aria-hidden="true">
      <svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.8" stroke-linecap="round" stroke-linejoin="round">

        <circle cx="12" cy="15.5" r="1" fill="currentColor" stroke="none"/>
      </svg>
    </div>
    <h3>Immutable system</h3>
    <p>The system image is read-only and reproducible; only the data partition is writable. Crash-restart and atomic updates are built in.</p>
  </div>
  <div class="pos-card">
    <div class="pos-card-icon amber" aria-hidden="true">

        <path d="M18 8a7 7 0 0 1 0 8"/>
      </svg>
    </div>
    <h3>Low-level audio</h3>
    <p>ALSA-backed audio through raylib's miniaudio, with device info and foreground-gated master volume and mute.</p>
  </div>
  <div class="pos-card">
    <div class="pos-card-icon red" aria-hidden="true">
      <svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.8" stroke-linecap="round" stroke-linejoin="round">

    <h3>Engine-agnostic SDK</h3>
    <p>A stable C ABI (<code>libplayos</code>) for input, storage, lifecycle, and cloud — portable across engines and toolchains.</p>
  </div>

    <p>Publish, discover, and install games; sync cloud saves, achievements, and leaderboards through self-hostable services.</p>
