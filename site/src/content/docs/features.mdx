PlayOS is built for one thing: playing games. A focused console experience — no desktop, no distractions, no Linux knowledge required.

    <h3>Controller-first shell</h3>
    <p>A Raylib-based interface driven entirely by gamepad. Games and menus are navigable with the same controls, end to end.</p>

    <p>A minimal wlroots compositor that permanently owns DRM/KMS — low-latency, tear-free output with no handoff to games.</p>

    <h3>Immutable system</h3>
    <p>The system image is read-only and reproducible; only the data partition is writable. Crash-restart and atomic updates are built in.</p>

    <p>ALSA-backed audio through raylib's miniaudio, with device info and foreground-gated master volume and mute.</p>
