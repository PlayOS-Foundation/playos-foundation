Thirteen repositories, one platform. Everything is open source under the PlayOS Foundation.

## Core runtime

<div class="pos-grid pos-grid-cols-2" style="margin-top:16px">
  <a class="pos-repo" href="https://github.com/PlayOS-Foundation/playos-init" target="_blank" rel="noopener">
    <span class="pos-repo-name">playos-init</span>
    <span class="pos-repo-desc">PID 1 init and system supervisor — boots the OS, supervises compositor/shell, launches games.</span>
  </a>
  <a class="pos-repo" href="https://github.com/PlayOS-Foundation/playos-compositor" target="_blank" rel="noopener">
    <span class="pos-repo-name">playos-compositor</span>
    <span class="pos-repo-desc">Minimal wlroots compositor owning DRM/KMS, Wayland sessions, focus, and input routing.</span>
  </a>
  <a class="pos-repo" href="https://github.com/PlayOS-Foundation/playos-shell" target="_blank" rel="noopener">
    <span class="pos-repo-name">playos-shell</span>
    <span class="pos-repo-desc">Raylib-based console interface for launching and managing applications.</span>
  </a>
  <a class="pos-repo" href="https://github.com/PlayOS-Foundation/playos-runtime" target="_blank" rel="noopener">
    <span class="pos-repo-name">playos-runtime</span>
    <span class="pos-repo-desc">Application lifecycle, package execution, runtime services, and OS integration.</span>
  </a>
  <a class="pos-repo" href="https://github.com/PlayOS-Foundation/playos-platform-api" target="_blank" rel="noopener">
    <span class="pos-repo-name">playos-platform-api</span>
    <span class="pos-repo-desc">Reference implementation of the public libplayos C ABI (input, storage, lifecycle, cloud).</span>
  </a>
</div>
