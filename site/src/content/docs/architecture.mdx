## Principles

<ul class="pos-principles">
  <li>Linux is the hardware layer, not the product.</li>
  <li>The system image is immutable; only the data partition is writable.</li>
  <li>The compositor permanently owns DRM/KMS — no handoffs to games.</li>
  <li>One game runs at a time; the shell always stays alive.</li>
  <li>Games target <code>playos-platform-api</code>; they never touch compositor or kernel internals.</li>
</ul>
